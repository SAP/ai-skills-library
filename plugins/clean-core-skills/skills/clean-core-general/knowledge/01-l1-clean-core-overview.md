> "Clean core-enabled continuous innovation can deliver up to **75% more incremental business value** over a 10-year period." *(SAP Analysis)*

**"Welcome to the Autonomous Enterprise. People set the direction. AI executes."**

## What is Clean Core?

> *"Clean core is a set of guiding principles that support continuous business transformation by helping organizations design agile, innovative, and efficient ERP systems."*

The principles focus on:
- Building **resilient business processes and extensions**
- Supported by **seamless integration**, **efficient operations**, and **high-quality data**

Clean core ensures the **solid foundation for Business AI adoption** on the journey to the Autonomous Enterprise.

### The Five Guiding Principles

Five clean core principles ensure that business-critical systems remain agile, cost-efficient, and ready to adopt innovations that drive growth.

By adopting standard processes while incorporating stable extensions and integrations for differentiating processes, the clean core principles help customers flexibly adapt to changing business requirements and adopt new capabilities.

| Principle | One-liner |
|---|---|
| **Extensibility** | Decouple extensions from the standard core. |
| **Business Processes** | Keep competitiveness while reducing complexity. |
| **Integration** | Keep the system landscape reliable and flexible. |
| **Data** | Control data according to the latest standards. |
| **Operations** | Keep the operations effective and efficient. |

## How to Establish a Clean Core

### The RISE with SAP Methodology

Three key components support the clean core journey:

1. **Standardized framework** — structured transformation approach aligned with clean core principles
2. **Expert guidance** — strategic advice from SAP, skilled partner ecosystem, quality gate reports with recommendations
3. **Agent-led transformation** — integrated toolchain accelerating every step, with Joule as the engagement layer

### Joule as the Engagement Layer

Joule provides transformation guidance and expert knowledge across every step of the journey. It is the engagement layer for:
- Transformation guidance and recommendations
- Guidance on how to utilize tools, AI assistants, and agents throughout the journey

### RISE with SAP Methodology Dashboard

The dashboard supports customers on their transformation journey to a clean core landscape:
- Comprehensive set of dashboards to track and monitor status
- Gather insights and provide recommendations for transformation projects
- Example: Review current extensions with the System View dashboard

### Clean Core Q-Gates

Clean core quality gates are embedded in the RISE with SAP Methodology — assessing current state, tracking progress, and continuously improving.

### Expert Guidance

- **Guided enablement from day one** — one-to-one onboarding, dedicated launch advisor, project tools and road maps, introduction to clean core principles
- **Expert advice from SAP** — strategic guidance, clean core quality gate reports, SAP Community
- **Skilled partner ecosystem** — implementation and operational support through certified partners
- **Additional SAP service offerings** — Advanced Success Plan, Max Success Plan

### The Wrap-Up: Four Clean Core Takeaways

1. **Follow the clean core principles** — modernize your complex IT landscape using a proven methodology and integrated toolchain.
2. **Adopt business AI and embrace innovation** — leverage SAP's unrivaled AI agents for smarter decisions and transformative outcomes.
3. **Deliver enterprise agility** — standardize where possible and create extensions for business-differentiating processes.
4. **Reduce operational costs** — streamline upgrades, eliminate legacy artifacts, reduce complexity and custom effort.
